## Where things live
- `MISSION.md` — charter, terms, the objective. Read first, rarely changes.
- `DECISIONS.md` — decision log (ADR-lite), newest on top. Read to learn "why".
- `ops/PARTNER-TASKS.md` — human-only task queue for the partner.
- `docs/` — deep reference docs (operating model, specs, plans). <List them as they exist.>
- `.claude/agents/` — specialized agent "employees". <List roles as defined.>
- `subprojects/<name>/` — where agents build each workstream.

## How memory works (the rules)
1. Small working set. Only MAP + MISSION + the task's docs load by default.
2. Everything else is retrieved via this MAP on demand.
3. Rank by relevance + salience, not pure recency. Recency is a tiebreaker.
4. Archive = move + keep indexed. Never delete the lossless record.
5. A consolidation pass periodically rebuilds indexes, dedupes, archives.
